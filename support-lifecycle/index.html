Maintenance scope

Active commercial subscriptions include product defect maintenance, security vulnerability response and updates for supported product versions, operating systems, cryptographic runtime and Python baseline. Custom development and customer infrastructure operations are not included unless separately agreed.

End of support

Before a currently supported version is designated end-of-support, ODRE AI will publish the affected version, effective date and available upgrade path through release notes, a security notice or direct customer notice where applicable. No future end-of-support date is currently published.

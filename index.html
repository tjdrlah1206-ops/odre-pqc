FastAPI Post-Quantum Security

Post-quantum API protection,
embedded in your FastAPI application.

ODRE PQC provides an application-embedded security boundary for FastAPI. The verified v0.1.4 scope combines ML-KEM-768, ML-DSA-65, strict sequence enforcement and selective fail-closed protection for /secure/*, with no silent classical-only downgrade. Integration remains install(app).

The Boundary

보호할 수 있음을 확인하기 전에는
비즈니스 로직을 실행하지 않습니다.

ODRE PQC의 핵심은 암호 알고리즘을 나열하는 것이 아니라, 애플리케이션의 보호 경로 앞에 검증 가능한 보안 경계를 세우는 것입니다.

01 · SELECTIVE FAIL-CLOSED
/secure/* 는 보호 실패 시 BLOCKEDPQC Provider, 키, 세션, Replay 상태가 정상적이지 않으면 보호 핸들러로 요청을 전달하지 않습니다.
02 · PUBLIC ROUTE ISOLATION
보호 경로만 닫고, Public은 고객 정책 유지PQC 장애가 전체 FastAPI 서비스를 불필요하게 중단시키지 않도록 보호영역과 비보호영역을 분리합니다.
03 · STRICT SEQUENCE
정확히 다음 Sequence만 허용Replay, Rollback, Gap, Mismatch를 핸들러 진입 전 차단합니다.
04 · NO SILENT FALLBACK
PQC가 깨져도 몰래 낮은 보안으로 내려가지 않음자동 Classical-only fallback을 하지 않습니다. 보호할 수 없으면 보호 경로는 닫힙니다.
Operator Experience

진단하고. 검증하고. 감시합니다.

암호학을 몰라도 세 명령어로 설치 상태와 실제 보호 상태를 확인할 수 있도록 설계했습니다.

01 · DIAGNOSE

Doctor

Python, Provider, Key, DB, 권한, 보안정책 등 설치 환경을 종합 진단합니다.

$ odre-pqc doctor
ALL CLEAR → READY
02 · VERIFY

Verify

실제 PQC 연산과 handshake, 세션 암호화, Replay/Tamper 차단을 self-test합니다.

$ odre-pqc verify
ALL PASS → VERIFIED
03 · MONITOR

Status

현재 Runtime, Security Boundary, Key Health, 만료 경고와 실제 보호상태를 읽기 전용으로 확인합니다.

$ odre-pqc status
PQC PROTECTION: ON
DOCTOR→VERIFY→STATUS→ 이상 발견 시 DOCTOR로 복귀

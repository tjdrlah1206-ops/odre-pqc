ODRE PQC

Post-quantum protection for production FastAPI services.

ODRE PQC adds a security boundary to protected application routes. If that protection cannot be verified, protected requests are blocked.

01

A protection boundary inside the application.

ODRE PQC runs with FastAPI and evaluates the security conditions for selected routes before the protected handler executes. Public routes can remain available according to application policy.

Explore the product
02

A small integration surface with explicit block conditions.

The application registers the boundary with install(app). Runtime identity, protocol state, session validity, sequence continuity, and authenticated request meaning are evaluated before protected execution.

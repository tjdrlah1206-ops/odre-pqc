Secure by design

The Device Code links this approval to the installation that created it. The installed client completes cryptographic proof and receives its Offline Lease.

Run this command on the installation server first:

odre-pqc-commercial activate
Copy the complete License ID from the delivery email.

The one-time code expires after 10 minutes. Generate a new code if it has expired.
The License Key is never placed in the URL, browser storage, server response, or application logs. The Device Code cannot query activation status.

Activation support

Existing Trial installation?

Keep it installed. A verified paid license changes the same installation to ACTIVE; reinstalling is unnecessary and does not reset the Trial.

Your data stays yours

ODRE verifies licensing metadata only. Customer request bodies, response bodies, and PQC plaintext are not collected.

ODRE PQCCompany

ODRE AI builds and maintains ODRE PQC.

Based in Korea, ODRE AI develops the product, maintains its releases, publishes scope-limited verification evidence, and operates the commercial and security contact routes listed on this site.

01

Why we build ODRE PQC

ODRE PQC helps teams add a server-side post-quantum protection boundary to selected FastAPI routes while preserving existing Android, iOS and Web clients and their HTTPS/TLS API contracts.

02

Product engineering principles

  • Defined scopeSeparate verified environments from combinations that have no public evidence.
  • Fail-closed behaviorDo not treat missing protection as permission to execute a protected handler.
  • Traceable evidenceBind public release identity and verification material to the artifact covered by that evidence.
  • MaintenanceAddress product defects, security vulnerabilities, and supported runtime changes within the published commercial scope.
03

Product and release responsibility

Product maintenance

ODRE AI develops and maintains ODRE PQC, its public documentation, release information, and supported product update path.

Security responsibility

Security boundaries, limitations, advisories, and the private vulnerability-reporting route are maintained as part of the product.

Evidence boundaries

Published validation results state their exact scope. Internal validation is not presented as independent third-party certification.

04

Cross-platform within a verified server scope

Public verification is limited to the two exact AMD64 server combinations below. Other operating systems, architectures, and Python versions are not described as verified.

WindowsWindows Server 2022 AMD64
CPython 3.12.10
LinuxUbuntu 24.04.4 LTS AMD64
CPython 3.12.3
Cryptographic runtimeOpenSSL 3.5.8
05

Contact routes

Sales, license, technical, and security inquiries use one published address with separate subject prefixes so each request can be routed clearly.

利用規約

ODRE PQC Production の商用ライセンスおよび関連サービスの利用条件です。

最終更新: 2026年9月15日

1. 製品とサービス

ODRE PQC Production 0.3.0は、FastAPIサーバーの保護対象の業務処理にポスト量子セキュリティを提供します。既存のAndroid・iOS・WebアプリのコードとHTTPS/TLS・API契約は維持されます。

リクエストはODRE Server Gateway → ODRE v3 → private Core → Protected Handlerの経路で検証されます。保護を確認できない場合は該当リクエストを拒否し、サーバー全体を停止する方式ではありません。保護範囲はサーバー内部であり、モバイル端末からサーバーまでのE2E PQCではありません。

2. ライセンスと Unit

購入はソフトウェアの所有権移転ではなく、限定的な使用権の付与です。1 Unitはライセンスされた本番サーバー／デプロイ1件を意味します。購入したUnit数を超えて使用することはできません。

3. サブスクリプションと自動更新

月額は1 Unitあたり USD 399、年額は1 Unitあたり USD 4,300で、1〜1,000 Unitsを購入できます。いずれも解約されるまで各請求周期で自動更新される recurring subscription です。Paddle が Merchant of Record として決済を処理し、決済、税、請求、一部の返金手続は Paddle の手続・方針の影響を受ける場合があります。

1〜1,000 Unitsで製品機能は共通です。機能別プラン、プロモーション、数量割引はありません。

4. 無料評価版

14日間の無料Trialは有料サブスクリプションへ自動移行せず、期限切れによる課金もありません。

購入後はインストールガイドに従い、使用する端末を登録して有効化してください。有効化には端末証明（Device proof）、Unit割り当て、署名付き利用権証明書（Offline Lease）の確認が含まれます。ライセンスメールの受信後も端末の有効化が必要です。

5. 支払失敗とライセンス状態

支払失敗、未払い、または有料サブスクリプションの有効性を確認できない場合、関連サービスやライセンス状態を制限、一時停止または終了することがあります。

必要な保護状態またはライセンス／Lease状態を検証できない場合、保護対象リクエストはHandler実行前に拒否されます。plaintext/classical fallbackは提供しません。

6. 禁止事項

  • 購入 Unit 数を超える利用
  • 無断の再配布、再販売、第三者へのライセンス提供
  • 適用法で明示的に許可される場合を除くリバースエンジニアリング、保護機能の毀損、ライセンス回避
  • 違法または権利侵害目的での利用

7. メンテナンスと対応環境

有料サブスクリプションには製品不具合修正、脆弱性対応、対応する PQC/OpenSSL/runtime 環境の更新が含まれます。セキュリティや互換性上の必要により対応環境が変更される場合があります。

8. 可用性と第三者インフラ

ODRE AI は合理的な運用努力を行いますが、無停止サービス、インターネット接続、第三者の決済・メール・ホスティング、顧客環境の継続可用性を保証しません。検証結果は定義された範囲の証拠であり、すべての攻撃への防御を保証するものではありません。

9. 規約変更

製品、法令、運用の変更を反映して本規約を更新する場合があります。重要な変更は Last updated または適切な通知方法で示します。

有料ODRE PQC Production取引のMerchant of RecordはPaddleです。本規約は法律上放棄できない権利を制限しません。

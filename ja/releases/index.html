Production Bundle

ODRE PQC Production 0.3.0

Production Bundle 0.3.0は、封印済みODRE PQC Core v0.2.9に、顧客向けインストール、Nativeランタイム、検証、ライセンス、デプロイメント各層を組み合わせた配布物です。

  • 公開済み2026-09-12
  • 証拠現在のartifact識別情報と整合性
封印Core

v0.2.9

Production Bundle 0.3.0が保持する封印Core検証基準です。LinuxのF-028-01経路にparent-directory identity lockingとparent-dirfd-relative promotionを追加し、封印WheelでWindows Server 2022、Ubuntu 22.04、Ubuntu 24.04、Debian 12、Rocky Linux 9、AlmaLinux 9のAMD64全検証範囲を再実行しました。

  • 公開済みSeptember 2026
  • 互換性に影響する変更公開v0.2.9白書に互換性に影響する変更は記載されていません。
  • 証拠現在のartifact識別情報と整合性
History

文書化された開発履歴

  • v0.2.8 → v0.2.9F-028-01の親object置換防御と対象・全体の再検証。
  • v0.2.6ネイティブ信頼、TOCTOU、file descriptor・inode識別の強化、provider・依存関係・設定pathの検証。
  • v0.2.4 → v0.2.5Ubuntu native ABIの欠落を確認し、shutdown exportとlifecycle動作を修正しました。その後の対象検証で追加findingがあり、release blockingを維持しました。
  • v0.1.4読み取り専用status観測を追加し、従来のセキュリティ契約を再確認しました。
  • v0.1.3厳密なnext-sequence検証と未対応応答契約のハンドラー前拒否により、v0.1.2の3件を解決しました。
  • v0.1.2機能検証後のclean-room攻撃検査で、sequence-gap許容とhandler orderingの2種3件を記録しました。
  • v0.1.1保護ルートのplaintext迂回を遮断し、セキュリティ失敗後のfail-closed handler動作を確立しました。

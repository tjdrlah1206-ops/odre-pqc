ODRE PQCSecurity

The conditions for protected handler execution.

ODRE PQC evaluates native runtime trust, handshake state, sessions, exact sequence continuity, authenticated request meaning, and supported response contracts as one boundary.

01

Security architecture

The shared Python boundary absorbs platform-specific native trust below a common request contract. Checks are ordered so unsupported or unverifiable protected requests are rejected before business handler entry.

  • AdmissionValidates message shape, required fields, encoding, aggregate size, and supported response forms.
  • Handshake & sessionBinds protocol version, algorithm set, endpoint materials, transcript, route meaning, and session identifier.
  • Sequence & replayRequires exactly the next sequence value and rejects duplicates, rollback, gaps, and concurrent double execution.
  • Semantic bindingBinds method, normalized path and query, security-relevant headers, payload, session, sequence, protocol, and message type.
  • Response bindingProtects supported status, content type, selected headers, cookies, response body, and request relationship.
02

Cryptographic roles

ML-KEM-768

Encapsulates and recovers shared secret material for the protocol.

ML-DSA-65

Authenticates handshake material and transcript integrity.

Hybrid handshake

Binds the required cryptographic components to the same peer, session, and route meaning.

Successful primitive calls alone do not establish protection. Runtime identity, transcript binding, key confirmation, and session creation must also complete.
03

Fail closed without a silent classical-only downgrade.

If runtime identity, provider or dependency trust, PQC self-tests, handshake transcript, active session, strict sequence, semantic binding, worker ownership, or safe recovery cannot be established, a protected route does not enter its handler.

Public routes may remain available under application policy. This distinction lets operators preserve an explicitly public health surface without treating an unavailable protection runtime as permission to bypass protected controls.

01

Qué es ODRE PQC

ODRE PQC no es una biblioteca criptográfica de uso general. Reúne identidad del runtime, handshake poscuántico, estado de sesión, secuencia estricta, defensa contra repetición, significado de la solicitud, respuestas protegidas y controles de ciclo de vida en un límite de ejecución FastAPI.

Invocar un algoritmo poscuántico no demuestra por sí solo que se cargó el runtime verificado ni que una repetición no pueda ejecutar dos veces un handler de negocio. El límite convierte esas preguntas en condiciones previas a la ejecución.

02

Cómo se integra

Clientes existentes → HTTPS/TLS → FastAPI → Gateway → ODRE v3 → Core → Protected Handler. Se conserva el contrato de la API del cliente. ODRE v3 opera entre Gateway y Core, no entre los dispositivos móviles y el servidor.

Existing clientHTTPS / FastAPIGateway / ODRE v3Private CoreProtected Handler

Instala el producto con el instalador de la plataforma. En FastAPI, importa ODRE PQC y llama a install(app). Core, Native, Gateway, licencia/lease, sesión/replay, Fail-Closed y el ciclo de actualización son gestionados internamente por ODRE.

Integración canónica de aplicaciones FastAPI

from fastapi import FastAPI
from odre_pqc import install

app = FastAPI()
install(app)

Esta es la integración canónica de la aplicación orientada al cliente. La instalación del producto sigue siendo un paso de plataforma separado; ODRE gestiona la integración interna de Core, Native, Gateway y Commercial gate.

El cliente es responsable de la aplicación FastAPI, las rutas y Handler protegidos, la autenticación y autorización de la aplicación, la lógica de negocio y DB, la validación de solicitudes protegidas reales y la aprobación de Production. ODRE gestiona el límite de seguridad interno y el ciclo de vida.
03

Rutas protegidas y públicas

Rutas protegidas

Una ruta protegida solo se ejecuta cuando se cumple el contrato de seguridad. Un mensaje malformado, sesión inválida, secuencia duplicada o omitida, discrepancia semántica o runtime no confiable bloquea el handler.

Rutas públicas

Las rutas públicas de health o información pueden seguir disponibles según la política de la aplicación cuando se bloquean rutas protegidas. Fail-closed no exige detener toda ruta pública.

04

Modelo de despliegue y operación

  • InstallVerifica la firma del Release Manifest y el SHA-256 del artefacto oficial. Instala el producto con .\install-odre-pqc.ps1 en Windows o sudo ./install-odre-pqc.sh en Linux.
  • initEjecuta odre-pqc init una sola vez y únicamente en una instalación nueva. Conserva la configuración, las claves y el estado existentes al actualizar o reinstalar.
  • doctorDiagnosticar plataforma, permisos, hashes, símbolos, dependencias y acceso al almacén de estado.
  • verifyodre-pqc verify ejecuta autopruebas criptográficas independientes de Core con claves y DB temporales, incluidas ML-KEM-768 y ML-DSA-65. Se ejecuta durante la instalación; no demuestra la integración FastAPI/Gateway del cliente ni debe repetirse con ese fin.
  • Integración FastAPIDespués de instalar el producto, importa ODRE PQC y aplica install(app). Configura las rutas y los Handler protegidos, además de la autenticación y autorización de la aplicación; ODRE gestiona la conexión interna de Core, Native, Gateway y el ciclo de vida.
  • statusCompleta la activación de Trial o de pago correspondiente y comprueba el estado del producto. Valida una solicitud protegida real en la aplicación del cliente, el comportamiento esperado de Handler y DB, y completa la aprobación de Production antes de abrir el tráfico.

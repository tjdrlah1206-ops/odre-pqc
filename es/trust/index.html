03

Evidencias de la versión

El alcance documentado cubre Windows Server 2022, Ubuntu 22.04, Ubuntu 24.04, Debian 12, Rocky Linux 9 y AlmaLinux 9 en AMD64.

Dentro del alcance validado, Bypass de Protected Handler, ejecución doble del Handler, Fallback Plaintext y Fallback Classical se registraron con valor 0.

Cobertura de validación

  • Rechazo de replay y manipulación
  • Gestión de sessions no válidas o caducadas
  • Core no disponible y fallos de lectura/escritura de state
  • Caducidad de session, restart y recovery
  • Presión de CPU, memoria, FD y handles
  • Bounded concurrency y protected soak de una hora

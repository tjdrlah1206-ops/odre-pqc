Core sellado

v0.2.9

Base de verificación del Core sellado conservada por Production Bundle 0.3.0. Se añadieron parent-directory identity locking y parent-dirfd-relative promotion para la ruta F-028-01 en Linux y se repitió el alcance completo de verificación AMD64 de Windows Server 2022, Ubuntu 22.04, Ubuntu 24.04, Debian 12, Rocky Linux 9 y AlmaLinux 9 sobre el Wheel sellado.

  • PublicadaSeptember 2026
  • Cambios incompatiblesEl whitepaper público de v0.2.9 no documenta cambios incompatibles.

History

Evolución documentada

  • v0.2.8 → v0.2.9Defensa contra sustitución del objeto padre F-028-01 y nueva verificación dirigida y completa.
  • v0.2.6Refuerzo de confianza nativa, TOCTOU e identidad de file descriptor e inode; validación de rutas de provider, dependencias y configuración.
  • v0.2.4 → v0.2.5Se detectó una omisión en la ABI nativa de Ubuntu y se corrigieron el export de shutdown y el ciclo de vida. Hallazgos posteriores mantuvieron bloqueada la versión.
  • v0.1.4Añadió observación status de solo lectura y confirmó de nuevo el contrato de seguridad anterior.
  • v0.1.3Cerró tres hallazgos de v0.1.2 con validación estricta de la siguiente secuencia y rechazo previo al handler de contratos de respuesta no compatibles.
  • v0.1.2Las pruebas de ataque clean-room conservaron tres hallazgos tras la verificación funcional: aceptación de saltos de secuencia y dos defectos de orden del handler.
  • v0.1.1Bloqueó la omisión plaintext de rutas protegidas y estableció comportamiento fail-closed del handler tras un fallo de seguridad.
Production Bundle 0.3.0 es la distribución actual para clientes. v0.2.9 sigue siendo la referencia de verificación del Core sellado; las versiones anteriores se muestran solo como historial de desarrollo y corrección.

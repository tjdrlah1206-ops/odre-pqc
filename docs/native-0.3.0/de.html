Native 0.3.0: Installation und Gerätewechsel

Verwenden Sie den geprüften Native-Bundle-Launcher für Ihr Betriebssystem. Vorhandene Aktionen: identity, trial, status, run und paid. Dies sind keine eigenständigen Shell-Befehle. Genaue Befehle und Pins stehen in der Anleitung Ihres Bundles.

Die Wheel-Befehle odre-pqc-commercial activate/deactivate sind keine Native-Kundenbefehle. Übertragen Sie keinen Wheel-Zustand auf Native.

Gerätewechsel und Serverumzüge benötigen derzeit Prüfung und Freigabe durch den Support. Der veröffentlichte Launcher bietet keinen selbstständigen Transfer. Eine Neuregistrierung überträgt keine vorhandene Unit. Wählen Sie ausdrücklich Transfer oder zusätzliche freie Unit. Starten Sie keine neue Trial als Ersatz für einen Transfer.

Bewahren Sie den alten Gerätezustand auf. Kopieren Sie keine DPAPI-Dateien, privaten Schlüssel oder Gateway-Identitäten. Das neue Gerät benötigt eigene Schlüssel und Identität. Eine alte Offline-Lease kann bis zum Ablauf gültig bleiben; ein Datenbanktransfer beweist keine exklusive Ausführung.

Trial-Transfers werden derzeit nicht unterstützt. Ein bezahlter Transfer ist erst nach Prüfung, geschützter Speicherung, Neustart und Gateway → Core → Handler-Prüfung abgeschlossen. Bei Antwortverlust oder Speicherfehlern denselben Vorgang mit Support wiederherstellen, keine weitere Unit belegen.

Kundenmeldungen

Keine freie Unit: Transfer oder zusätzliche Kapazität. Abgelaufener Code: nach ausdrücklicher Ablehnung neu anfordern. Freigabe ausstehend: Support bearbeitet den Vorgang. Bereits freigegeben: vorhandenes Ergebnis wiederherstellen. Der vollständige Native-Transfer wird noch validiert.

Der RC24-Download wird bis zum Abschluss der Transferprüfung nicht ersetzt. Fehlendes öffentliches Windows-Authenticode-Vertrauen bleibt eine separate bekannte Einschränkung.

Native 0.3.0 설치와 장치 교체

검증한 Native Bundle의 OS별 launcher를 사용합니다. 현재 고객 action은 identity, trial, status, run, paid입니다. 이는 단독 셸 명령이 아닌 action 이름입니다. 정확한 실행 명령과 pin 설정은 해당 Bundle에 동봉된 가이드를 따르세요.

Wheel의 odre-pqc-commercial activate/deactivate는 Native 고객 명령이 아닙니다. Wheel 상태로 Native를 활성화하거나 이전하지 마세요.

장치 교체·서버 이전은 현재 지원 검토와 승인이 필요합니다. 배포된 Native launcher에는 고객 직접 이전 기능이 없습니다. 새 장치 등록만으로 기존 Unit이 이전되지 않습니다. 기존 Unit 이전과 여유 Unit 추가 할당 중 하나를 지원 담당자와 명시적으로 선택하세요. Trial 재등록으로 이전을 대신하지 마세요.

기존 장치 상태를 보존하세요. DPAPI 파일·개인키·Gateway identity를 새 장치에 복사하지 마세요. 새 장치는 자체 키와 identity가 필요합니다. 기존 Offline Lease는 만료까지 유효할 수 있으므로 서버 이전 완료만으로 실행 독점이 보장되지는 않습니다.

Trial 이전은 현재 지원하지 않습니다. 유료 이전 완료는 새 장치의 검증·보호 저장·재시작 및 Gateway → Core → Handler 확인 후 판정합니다. 응답 유실이나 저장 실패 시 동일 작업 복구를 지원에 요청하세요. 새 Unit 할당으로 재시도하지 마세요.

고객 오류 안내

LICENSE_UNIT_LIMIT: 사용 가능한 Unit이 없습니다. 기존 장치 이전 또는 추가 구매가 필요합니다. 등록 코드 만료: 명시적으로 만료가 확인된 경우 코드를 다시 발급하세요. 이전 승인 대기: 지원 승인 처리 중입니다. 이미 승인된 이전: 기존 결과를 조회·복구하며 새 이전을 만들지 않습니다. 구분할 상태를 설명한 것으로, Native 이전 전체 기능은 아직 검증 중입니다.

장치 이전 검증이 완료될 때까지 RC24 다운로드 교체를 보류합니다. Windows Public Authenticode 미제공은 별도의 Known Limitation입니다.

Native 0.3.0: installation and device replacement

Use the verified Native bundle and its platform-specific launcher. Existing customer actions are identity, trial, status, run and paid. They are action names, not standalone shell commands. Follow the commands and pinned configuration in the guide supplied with your exact bundle.

The Wheel commands odre-pqc-commercial activate/deactivate are not Native customer commands. Do not use Wheel state to activate or move a Native installation.

Device or server replacement currently requires support review and approval. Self-service transfer is not available in the released Native launcher. New registration does not transfer an existing Unit. Choose explicitly between transferring an existing Unit and allocating an additional available Unit with support; do not repeat Trial activation as a migration workaround.

Keep the original device state. Do not copy DPAPI blobs, private keys or Gateway identity to the replacement host. A new device needs its own keys and identity. An old offline lease can remain valid until expiry; a server-side transfer alone does not prove exclusive execution.

Trial transfer is not currently supported. A paid transfer is not complete until the destination has verified and durably stored its authorization, restarted successfully and passed Gateway → Core → Handler checks. If a response is lost or local saving fails, contact support to recover the same operation; do not allocate another Unit.

Customer messages

No available Unit: request an existing-device transfer or purchase additional capacity. Expired registration challenge: request a new code only after an explicit expiry rejection. Approval pending: wait for support. Already approved: recover the existing result; do not start a second transfer. These are the intended distinct states; the complete Native transfer workflow is still under validation.

RC24 download replacement remains on hold while device-transfer validation is incomplete. Windows Public Authenticode remains a separate known limitation.

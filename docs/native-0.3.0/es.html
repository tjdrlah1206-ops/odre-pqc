Native 0.3.0: instalación y cambio de dispositivo

Utiliza el launcher del Bundle Native verificado para tu sistema. Las acciones existentes son identity, trial, status, run y paid; no son comandos independientes. Sigue los comandos y pins de la guía incluida en tu Bundle.

Los comandos Wheel odre-pqc-commercial activate/deactivate no son comandos Native. No utilices el estado Wheel para activar o trasladar Native.

El cambio de dispositivo o servidor requiere revisión y aprobación de soporte. El launcher publicado no permite el traslado autónomo. Un registro nuevo no transfiere una Unit. Elige expresamente transferir una Unit existente o asignar otra disponible. No repitas Trial como sustituto de un traslado.

Conserva el estado original. No copies DPAPI, claves privadas ni la identidad Gateway. El dispositivo nuevo necesita claves e identidad propias. La Lease offline anterior puede seguir vigente hasta su vencimiento; el traslado en la base de datos no demuestra exclusividad de ejecución.

El traslado Trial aún no está soportado. Un traslado de pago termina tras validar, guardar de forma protegida, reiniciar y comprobar Gateway → Core → Handler. Ante pérdida de respuesta o fallo al guardar, recupera la misma operación con soporte; no asignes otra Unit.

Mensajes para clientes

Sin Unit disponible: traslado o compra adicional. Código vencido: solicita otro tras un rechazo explícito. Aprobación pendiente: soporte la está procesando. Ya aprobado: recupera el resultado existente. El flujo completo de traslado Native sigue en validación.

La sustitución de la descarga RC24 queda pendiente de completar la validación del traslado. La falta de confianza pública Windows Authenticode es una limitación conocida independiente.

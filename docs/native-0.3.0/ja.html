Native 0.3.0：インストールと端末交換

検証済みNative BundleのOS別launcherを使ってください。現在のactionはidentity、trial、status、run、paidです。単独のシェルコマンドではありません。実際のコマンドとpin設定は同梱ガイドに従ってください。

Wheelのodre-pqc-commercial activate/deactivateはNative向けコマンドではありません。Wheelの状態をNativeへ移さないでください。

端末交換・サーバー移行には現在サポートの審査と承認が必要です。公開launcherにセルフサービス移行機能はありません。新規登録だけでは既存Unitは移転しません。既存Unit移転と空きUnit追加割当を明示的に選択し、Trial再登録で代用しないでください。

元の端末状態を保持してください。DPAPI、秘密鍵、Gateway identityを複製しないでください。新端末には固有の鍵とidentityが必要です。旧Offline Leaseは期限まで有効な場合があり、DB上の移転だけで排他的実行は保証されません。

Trial移転は未対応です。有料移転の完了には新端末での検証、保護保存、再起動、Gateway → Core → Handlerの確認が必要です。応答消失や保存失敗は同じ処理をサポート経由で復旧し、追加Unitを割り当てないでください。

エラーの案内

Unit不足：既存端末の移転または追加購入。コード期限切れ：明示的な拒否を確認して再発行。承認待ち：サポート対応中。承認済み：既存結果を復旧し二重移転しない。これらは区別すべき状態であり、Native移転全体は検証中です。

端末移転の検証完了までRC24ダウンロードの置換を保留します。Windows Public Authenticode未提供は別の既知の制限です。

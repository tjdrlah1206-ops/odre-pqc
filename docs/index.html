Quick start

The public overview documents the supported sequence below. Exact package sources, customer credentials, and license procedures are delivered through the official product channel.

Install official wheel
odre-pqc init
odre-pqc doctor
odre-pqc verify
install(app)
Start application
odre-pqc status
Before installation, compare the wheel SHA-256 with the value in Release Integrity. Do not use an artifact whose hash does not match.

Installation

Install the official v0.2.9 wheel in the supported Python environment, initialize the local platform runtime, and resolve every doctor or verify condition before enabling protected traffic.

  1. Confirm Windows Server 2022 AMD64 or Ubuntu 24.04 LTS AMD64 and CPython 3.12.
  2. Obtain the wheel and required customer materials from the official delivery channel.
  3. Verify the wheel SHA-256 and follow the customer installation guide.
  4. Run init, doctor, and verify before application startup.
  5. Register the boundary with install(app) and confirm status after startup.

Operations

A normal shutdown stops new protected admission, drains bounded in-flight work, disposes sessions and leases, closes native resources, releases locks, and records stopped state. Crash recovery re-checks ownership, stale locks, sessions, and partially initialized runtime before returning to Ready.

Doctor

Diagnoses the operating system, architecture, Python runtime, file and parent permissions, hashes, symbols, providers, dependencies, and access to local state. Treat an unresolved condition as a deployment blocker for protected traffic.

Verify

Checks package and runtime versions, native loading, real ML-KEM-768 and ML-DSA-65 self-tests, hybrid handshake, session lifecycle, protected round trip, and absence of automatic classical-only downgrade.

Status

Reads operational state without changing sessions or leases and without exposing secrets or sensitive paths. This is a product command, not a public service-status dashboard.

Troubleshooting

  • Hash mismatch: stop installation and obtain the artifact again through the official delivery route.
  • Unsupported OS, architecture, or Python version: do not describe the environment as verified; contact technical support before deployment.
  • Doctor or verify failure: keep protected traffic disabled until the reported condition is resolved.
  • Missing license email: do not purchase again; use the recovery page or license support.
  • Operational instructions not covered publicly: use the customer guide supplied with the release.

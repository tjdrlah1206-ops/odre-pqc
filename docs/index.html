Installation

ODRE PQC v0.2.9 is distributed through the controlled evaluation or customer delivery process. Verify the received artifact against the published SHA-256 before installation. Do not install an artifact from an unapproved source or continue after a hash mismatch.

  1. Confirm the operating system, architecture and Python baseline.
  2. Receive the sealed product package and customer guide through the approved delivery process.
  3. Verify the exact artifact identity before installation.
  4. Install in a controlled environment with the permissions described in the delivered guide.

License Activation

A 14-day evaluation and a paid commercial subscription use the product's approved activation process. Each Unit represents one independent licensed production deployment or installation. Enter license credentials only in the installed product's activation interface; never paste a License Key into a public website, email reply, chat or source repository.

Request a 14-day evaluation · Confirm an existing purchase or recover delivery

Operations

Keep the license path outside customer request processing. Customer application request and response bodies are not routed to ODRE for licensing. Maintain the surrounding controls required for a production service: TLS, authentication, authorization, host patching, secret management, monitoring, backup, rollback and change control.

Doctor

odre-pqc doctor checks the installation and environment conditions exposed by the product. Treat a failed or ambiguous diagnostic as a deployment blocker for protected traffic until the cause is resolved.

odre-pqc doctor

Verify

odre-pqc verify exercises the configured product cryptography and protection checks. A successful local result is one deployment control; it does not expand the published verification scope or replace operational risk assessment.

odre-pqc verify

Status

Run odre-pqc status after the application starts. Use authenticated runtime status together with your service health and deployment controls. Do not interpret an unauthenticated string or a stale file as proof that protection is active.

odre-pqc status

FAQ

What is a Unit?

One Unit is one independent licensed production deployment or installation. The current public material does not define each worker process as a separate Unit.

How are multiple workers counted?

Workers within one licensed deployment are not described as separate installations in the current Unit definition. Confirm unusual topologies with license support before purchase.

How are virtual machines and containers counted?

A separate independent installation or production deployment requires its own Unit. For autoscaling, cloned, ephemeral or orchestrated deployments, confirm the planned topology with ODRE AI before purchase.

How does the 14-day Trial work?

The evaluation is separate from payment-provider billing trials. It starts through the approved product activation process and does not become a paid subscription merely by downloading.

What happens if internet connectivity is interrupted?

The licensing design keeps service checks out of each customer request. Exact offline lease and renewal behavior is defined by the delivered product and license terms; contact support for deployment planning.

Can a license move to another installation?

License transfer or reactivation requires the approved support and device verification process. Do not copy installation state or credentials between systems.

When does access end after cancellation?

Paid use continues only through the applicable paid period and license state under the commercial terms. Review the subscription and cancellation provisions before purchase.

How do I purchase 21 Units or more?

Use Enterprise Licensing for volume terms, deployment planning and procurement support.

Are security updates included?

Commercial subscriptions include maintenance and security updates for supported versions and environments, subject to the published support policy.

Which operating systems are verified?

For v0.2.9: Windows Server 2022 AMD64 and Ubuntu 24.04 LTS AMD64, with Python 3.12.

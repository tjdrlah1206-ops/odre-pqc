ODRE PQC 0.3.1 / RC2

RC2 설치·Native 명령

고객 ZIP과 독립적으로 승인된 verifier kit를 먼저 검증하세요. 새 보호된 immutable 디렉터리에 설치한 뒤 RC2 Native 설치 가이드를 따르세요.

Windows: 승인된 provisioning context에서 검증한 배포본의 .\install-odre-pqc.ps1 -InstallDirectory <NEW_ABSOLUTE_DIRECTORY>를 실행합니다.

Linux: 승인된 provisioning context에서 ./install-odre-pqc.sh를 실행합니다. 신뢰된 Python 3.12·OpenSSL 3.5.8과 승인된 prerequisite 입력이 필요하며 설치 대상은 새 디렉터리여야 합니다.

ODRE_TRUSTED_PYTHON
ODRE_TRUSTED_PYTHON_SHA256
ODRE_INSTALL_PREREQUISITES
ODRE_INSTALL_PREREQUISITES_SHA256
ODRE_INSTALL_DIRECTORY

설치·활성화·runtime 확인

Windows: WINDOWS_SERVER_2022\runtime\python.exe + WINDOWS_SERVER_2022\odre-core-cli.py / odre-native.py
Linux: LINUX_FAMILY/runtime/bin/python3.12 + LINUX_FAMILY/odre-core-cli.py / odre-native-ubuntu.py

# Windows — installed WINDOWS_SERVER_2022 directory
& .\runtime\python.exe -B .\odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>
# Linux — installed LINUX_FAMILY directory
./runtime/bin/python3.12 -B ./odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>

init — init은 Native device identity를 생성합니다. 신규 설치에서만 사용하세요.

doctor — doctor는 활성화 없이 서명된 runtime을 검사합니다.

verify — verify는 기존 Lease admission 이후 Core를 검사합니다. 실제 Gateway → Core → Protected Handler 경로는 별도로 확인하세요.

status — status는 Native 상태를 읽습니다. Trial·Paid 활성화는 설치된 Native launcher와 승인된 로컬 trust 설정을 사용합니다.

--state-directory · --trust-config · --trust-pin

Trial과 Paid는 동일한 ODRE PQC 0.3.1 / RC2 ZIP을 사용합니다. 다운로드만으로 Trial이나 결제가 시작되지 않습니다.

기존 identity·License·Unit·Lease·device state를 보존하세요. 기존 설치본을 재초기화하거나 private material을 다른 장치에 복제하지 마세요.

서명된 로컬 업데이트

설정된 고객 Updater는 승인된 로컬 입력을 15초마다 검사합니다. 서명·무결성·호환성을 검증한 입력을 로컬 AUM에 전달합니다. 이 릴리스에는 중앙 Update Server에서 새 버전을 내려받는 기능이 없습니다.

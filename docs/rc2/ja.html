ODRE PQC 0.3.1 / RC2

RC2導入・Nativeコマンド

顧客ZIPと独立して承認されたverifier kitを先に検証します。新しい保護されたimmutableディレクトリへ導入し、RC2 Nativeガイドを使用してください。

Windows：承認されたprovisioning contextで検証済み配布物の .\install-odre-pqc.ps1 -InstallDirectory <NEW_ABSOLUTE_DIRECTORY> を実行します。

Linux：承認されたprovisioning contextで ./install-odre-pqc.sh を実行します。信頼済みPython 3.12、OpenSSL 3.5.8、承認済みprerequisite入力が必要です。導入先は新しいディレクトリです。

ODRE_TRUSTED_PYTHON
ODRE_TRUSTED_PYTHON_SHA256
ODRE_INSTALL_PREREQUISITES
ODRE_INSTALL_PREREQUISITES_SHA256
ODRE_INSTALL_DIRECTORY

導入・有効化・runtime確認

Windows: WINDOWS_SERVER_2022\runtime\python.exe + WINDOWS_SERVER_2022\odre-core-cli.py / odre-native.py
Linux: LINUX_FAMILY/runtime/bin/python3.12 + LINUX_FAMILY/odre-core-cli.py / odre-native-ubuntu.py

# Windows — installed WINDOWS_SERVER_2022 directory
& .\runtime\python.exe -B .\odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>
# Linux — installed LINUX_FAMILY directory
./runtime/bin/python3.12 -B ./odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>

init — initはNative device identityを作成します。新規導入時のみ使用します。

doctor — doctorは有効化せずに署名済みruntimeを検査します。

verify — verifyは既存Lease admission後にCoreを検査します。実際のGateway → Core → Protected Handler経路は別途確認します。

status — statusはNative状態を読みます。Trial・Paidの有効化には導入済みNative launcherと承認済みローカルtrust設定を使用します。

--state-directory · --trust-config · --trust-pin

TrialとPaidは同じODRE PQC 0.3.1 / RC2 ZIPを使用します。ダウンロードだけではTrialも決済も開始しません。

既存のidentity、License、Unit、Lease、device stateを保持してください。既存環境の再初期化やprivate materialの別デバイスへのコピーは禁止です。

署名済みローカル更新

設定済みの顧客Updaterは承認済みローカル入力を15秒ごとに確認します。署名・完全性・互換性を検証してローカルAUMへ渡します。このリリースは中央Update Serverから新バージョンをダウンロードしません。

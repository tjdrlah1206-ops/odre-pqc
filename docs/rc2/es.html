ODRE PQC 0.3.1 / RC2

Instalación RC2 y comandos Native

Verifique primero el ZIP y el kit verificador aprobado por un canal independiente. Instale en un directorio nuevo, protegido e inmutable y siga la guía Native de RC2.

Windows: ejecute .\install-odre-pqc.ps1 -InstallDirectory <NEW_ABSOLUTE_DIRECTORY> desde la entrega verificada en el contexto de aprovisionamiento aprobado.

Linux: ejecute ./install-odre-pqc.sh en el contexto aprobado. Se requieren Python 3.12 y OpenSSL 3.5.8 de confianza y entradas de requisitos aprobadas. El directorio de destino debe ser nuevo.

ODRE_TRUSTED_PYTHON

Instalación, activación y comprobación runtime

Windows: WINDOWS_SERVER_2022\runtime\python.exe + WINDOWS_SERVER_2022\odre-core-cli.py / odre-native.py
Linux: LINUX_FAMILY/runtime/bin/python3.12 + LINUX_FAMILY/odre-core-cli.py / odre-native-ubuntu.py

# Windows — installed WINDOWS_SERVER_2022 directory
& .\runtime\python.exe -B .\odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>
# Linux — installed LINUX_FAMILY directory
./runtime/bin/python3.12 -B ./odre-core-cli.py doctor --state-directory <STATE_DIRECTORY>

init — init crea la identidad del dispositivo Native; úselo solo para una instalación nueva.

doctor — doctor comprueba el runtime firmado sin activación.

verify — verify comprueba Core después de la admisión de una Lease existente. Verifique por separado Gateway → Core → Protected Handler.

status — status lee el estado Native. Trial y Paid se activan con el launcher instalado y la configuración local de confianza aprobada.

--state-directory · --trust-config · --trust-pin

Trial y Paid usan el mismo ZIP ODRE PQC 0.3.1 / RC2. Descargar no inicia Trial ni pago.

Conserve identity, License, Unit, Lease y estado del dispositivo. No reinicialice instalaciones existentes ni copie material privado a otro dispositivo.

Actualizaciones locales firmadas

El Updater configurado comprueba entradas locales aprobadas cada 15 segundos. Tras verificar firma, integridad y compatibilidad, las entrega al AUM local. Esta versión no descarga versiones nuevas desde un Update Server central.

ODRE PQC 0.3.1 RC1 Windows 검증 및 trust model

현재 authority: Product 0.3.1 RC1 · Release 64 · Closure g270 · 공식 지원 OS 6/6 PASS.

Windows Server 2022 상태

지원 · 검증 · PASS
Windows Server 2022 AMD64는 검증된 6개 운영체제 중 하나입니다. 이 결과와 Public Authenticode 유무는 별개입니다.

공식 릴리스 검증 모델

Release pin → CMS signing authority → signed CRL → independent verifier → signed outer inventory와 인증된 Product envelope → manifest/SHA 순서입니다. 하나라도 실패하면 설치를 중단합니다.

독립 검증 순서

  1. 독립적으로 인증한 공식 채널에서 Release 64 해시와 pin을 확보합니다.
  2. 제품 코드 실행 전에 Customer Delivery 파일명과 SHA-256을 검증합니다.
  3. 고정된 root와 signer로 detached CMS와 signed CRL을 검증합니다. Private Root를 Windows Trusted Root에 등록하지 않습니다.
  4. signed OUTER_INVENTORY, Product envelope, Product SHA-256, 내부 Ed25519 manifest, runtime inventory 및 sealed Core identity를 검증합니다.
  5. 모든 Gate PASS 후에만 설치하며 identity, License, Unit, Lease와 Gateway state를 보존합니다.

Windows Public Authenticode 구분

Public Authenticode는 릴리스 trust authority가 아니며 Windows Server 2022 지원 또는 6/6 검증 결과와 혼동하지 않습니다. Windows 보안 통제를 약화하지 않습니다.

Evidence 경계와 향후 publication binding

Release 64 CMS는 signed outer file inventory와 내부 Product envelope를 결속합니다. g270 SHA256SUMS는 최종 Customer Delivery ZIP 해시를 기록하지만 Release 64에는 최종 outer ZIP container bytes를 결속하는 Signed Publication Manifest가 없습니다. 이미 구현됐다고 주장하지 않습니다. 향후 새 Release부터 동일 signing authority 아래 파일명, 크기, SHA-256, Release와 Closure를 결속합니다. Release 64 Evidence는 소급 수정하지 않습니다. 6/6은 제품 Evidence이며 제3자 인증이 아닙니다.

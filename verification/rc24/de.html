Known Limitation — Authenticode
RC24 bietet kein Windows Public Authenticode Trust. Windows kann einen unbekannten Herausgeber melden; Unternehmensrichtlinien können die Ausführung blockieren. CMS ersetzt keine Windows-Richtlinie. Deaktivieren Sie weder SmartScreen noch Anwendungskontrolle, Sperrprüfung oder Sicherheitssoftware.

Externer Verifier und öffentliche Pins

Beziehen Sie Verifier und Pins vor jeder Codeausführung über einen unabhängig authentifizierten Herausgeberkanal. Ein Hash neben einem nicht vertrauenswürdigen Download oder separates Hosting allein authentifiziert den Herausgeber nicht.

Erforderliche Prüfreihenfolge

  1. Authentifizieren Sie den Release-Datensatz und vergleichen Sie Kunden-ZIP, Verifier-ZIP und Policy-Hashes. Entpacken Sie nur das geprüfte externe Kit in ein neues Verzeichnis. Führen Sie keinen Verifier aus einem ungeprüften Produkt aus.
  2. Verwenden Sie vertrauenswürdiges Python 3.12 mit cryptography und genehmigtes PowerShell. Erzeugen Sie die lokale Konfiguration aus der fixierten Policy und notieren Sie trust_sha256.
  3. Prüfen Sie Root-/CMS-Signer-Pins, Zertifikatsgültigkeit/EKU, signierte CRL mit Aussteller, Signatur, Gültigkeit und Sperrstatus sowie die CMS-Signatur. Keine Registrierung im Windows-Root-Speicher.
  4. Prüfen Sie authentifizierten Envelope, Produkt-ZIP-Hash, Generation, Pfade/CRC/vollständige Dateiliste und Hashes, Ed25519-Manifest, verschlüsselten Core und Laufzeitinventar.
  5. Erst nach Erfolg wird die Installation atomar bereitgestellt. Der offizielle Launcher prüft Native vor Ausführung; Native prüft Laufzeit, Authority und Lease. Bei Fehlern stoppen; keine Umgehung durch manuelles Entpacken oder direkte EXE-Ausführung.

Windows-Prüfbefehle

Vorlagen benötigen authentifizierte RC24-Dateien, vertrauenswürdiges Python 3.12/cryptography, genehmigten PowerShell-Hash und Betreiber-SID. Das Hashen einer beliebigen Datei genehmigt sie nicht. Im geprüften externen Kit ausführen; kein Zertifikatsimport und keine ExecutionPolicy-Umgehung.

$verifierZip = '.\ODRE_PQC_EXTERNAL_VERIFIER_0.3.0.zip'
$expectedVerifier = '182ED150DC01064ADDD1AEBEEA8BE9F9CCC7BAA7E577E9144F11B52DF18D7C80'
if ((Get-FileHash -LiteralPath $verifierZip -Algorithm SHA256).Hash -cne $expectedVerifier) {
    throw 'VERIFIER_ZIP_HASH_MISMATCH'
}
# Only after authenticating the expected pin; destination must be new.
if (Test-Path -LiteralPath '.\rc24-verifier') { throw 'DESTINATION_EXISTS' }
Expand-Archive -LiteralPath $verifierZip -DestinationPath '.\rc24-verifier'
Set-Location -LiteralPath '.\rc24-verifier' 
$delivery = '<RC24_DELIVERY_DIRECTORY>\ODRE_PQC_PRODUCTION_0.3.0_CUSTOMER_DELIVERY.zip'
$expectedDelivery = '3A14BE4D12241CB2C675626958E7F6B6E4A86F2A77D53D92D14526B3277B5A0B'
if ((Get-FileHash -LiteralPath $delivery -Algorithm SHA256).Hash -cne $expectedDelivery) {
    throw 'RC24_DELIVERY_HASH_MISMATCH'
}
# Unpack this authenticated outer delivery only; do not extract the inner product ZIP.
if (Test-Path -LiteralPath '.\rc24-delivery') { throw 'DESTINATION_EXISTS' }
Expand-Archive -LiteralPath $delivery -DestinationPath '.\rc24-delivery' 
$python = '<TRUSTED_PYTHON_3_12_ABSOLUTE_PATH>'
& $python -B .\prepare_customer_verifier_config.py `
  --policy .\verifier-policy.json `
  --policy-sha256 '4BADE8AF01F2BC1F899F2B226604C690C27D6A7AE0A19C62A879AFCF90622FF5' `
  --platform windows `
  --cms-tool '<APPROVED_POWERSHELL_EXE_ABSOLUTE_PATH>' `
  --cms-tool-sha256 '<INDEPENDENTLY_APPROVED_POWERSHELL_SHA256>' `
  --operator-sid '<APPROVED_OPERATOR_SID>' `
  --output .\local-trust.json
if ($LASTEXITCODE -ne 0) { throw 'VERIFIER_CONFIGURATION_FAILED' }
& $python -B .\trusted_preinstall.py `
  --bundle '<RC24_PRODUCT_DIRECTORY>\ODRE_PQC_PRODUCTION_0.3.0.zip' `
  --envelope '<RC24_PRODUCT_DIRECTORY>\bundle-envelope.json' `
  --cms '<RC24_PRODUCT_DIRECTORY>\envelope.p7s' `
  --trust .\local-trust.json `
  --trust-sha256 '<RETURNED_TRUST_SHA256>' `
  --expected-bundle-sha256 '2A49C6F2FE0BA0702E615B6A55434E52F7826340B636FAB9F6FA1062ED389DC3'
if ($LASTEXITCODE -ne 0) { throw 'PREINSTALL_FAILED' }

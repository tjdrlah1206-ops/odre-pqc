Windows Server 2022 AMD64 es uno de los seis sistemas verificados. Este resultado es independiente de Public Authenticode.

Modelo oficial de verificación

Release pin → autoridad CMS → CRL firmada → verificador independiente → inventario externo firmado y Product envelope → manifiesto/SHA. Cualquier fallo detiene la instalación.

Procedimiento independiente

  1. Obtenga hashes y pins de Release 64 mediante un canal oficial autenticado independientemente.
  2. Verifique nombre y SHA-256 del Customer Delivery antes de ejecutar código.
  3. Verifique CMS y CRL firmada con root y signer fijados; no importe Private Root.
  4. Verifique OUTER_INVENTORY, Product envelope, Product SHA, manifiestos Ed25519, runtime inventory y sealed Core.
  5. Instale solo tras todos los PASS y conserve identity, License, Unit, Lease y Gateway state.

Contexto de Windows Public Authenticode

Public Authenticode no es la autoridad de confianza del release y no se confunde con soporte Windows ni 6/6 PASS. No debilite controles de Windows.

Límite de Evidence y binding futuro

El CMS de Release 64 vincula inventario externo y Product envelope. g270 SHA256SUMS registra el hash final, pero Release 64 no contiene Signed Publication Manifest para los bytes del ZIP externo. No se presenta como implementado. Desde un futuro Release nuevo, la misma signing authority vinculará filename, size, SHA-256, Release y Closure. Evidence de Release 64 no se modifica retroactivamente. 6/6 es evidencia de producto, no certificación independiente.

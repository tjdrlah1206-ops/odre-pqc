Known Limitation — Authenticode
RC24 no proporciona Windows Public Authenticode trust. Windows puede indicar un editor desconocido o una cadena no confiable; las políticas empresariales pueden impedir la ejecución. CMS no sustituye estas políticas. No desactives SmartScreen, el control de aplicaciones, la comprobación de revocación ni el software de seguridad.

Verifier externo y pins públicos

ODRE_PQC_EXTERNAL_VERIFIER_0.3.0.zip (27,196 bytes) · SHA-256 · release-pins.json · Registro de versión en GitHub

Obtén el verifier y los pins desde un canal cuyo editor hayas autenticado de forma independiente antes de ejecutar código. Un hash junto a una descarga no confiable o un alojamiento separado no autentica por sí solo al editor.

Orden obligatorio de verificación

  1. Autentica el registro de versión y compara los hashes del ZIP de cliente, verifier externo y policy. Extrae solo el kit externo verificado en un directorio nuevo. No ejecutes un verifier obtenido únicamente de un producto sin verificar.
  2. Utiliza Python 3.12 con cryptography de confianza y PowerShell aprobado. Genera la configuración local desde la policy fijada y conserva el trust_sha256 devuelto.
  3. Comprueba pins de Root y firmante CMS, validez/EKU de certificados, emisor/firma/vigencia/revocación de la CRL firmada y CMS separado. No se registra la Root en el almacén de Windows.
  4. Verifica el envelope autenticado, hash del ZIP del producto, generación, rutas/CRC/cobertura y hashes, manifiesto Ed25519, Core cifrado e inventario del runtime.
  5. Solo tras el éxito se publica la instalación de forma atómica. El launcher oficial verifica Native antes de ejecutarlo; Native verifica runtime, authority y Lease. Detente ante errores; no los evites extrayendo manualmente ni ejecutando una EXE suelta.

La CRL incluida vence el 2026-09-29 a las 11:08:49 UTC. Es una instantánea offline limitada, no una garantía de revocación inmediata. Obtén una CRL actual autenticada antes del vencimiento. Una CRL caducada o inválida debe detener la instalación. La ruta local de CRL de Authenticode es una limitación separada.

Comandos de verificación de Windows

Estas plantillas requieren RC24 autenticado, Python 3.12/cryptography de confianza, hash de PowerShell aprobado y SID del operador. Calcular el hash de un ejecutable arbitrario no lo aprueba. Ejecuta desde el kit externo verificado; sin importar certificados ni evitar ExecutionPolicy.

$verifierZip = '.\ODRE_PQC_EXTERNAL_VERIFIER_0.3.0.zip'
$expectedVerifier = '182ED150DC01064ADDD1AEBEEA8BE9F9CCC7BAA7E577E9144F11B52DF18D7C80'
if ((Get-FileHash -LiteralPath $verifierZip -Algorithm SHA256).Hash -cne $expectedVerifier) {
    throw 'VERIFIER_ZIP_HASH_MISMATCH'
}
# Only after authenticating the expected pin; destination must be new.
if (Test-Path -LiteralPath '.\rc24-verifier') { throw 'DESTINATION_EXISTS' }
Expand-Archive -LiteralPath $verifierZip -DestinationPath '.\rc24-verifier'
Set-Location -LiteralPath '.\rc24-verifier' 
$delivery = '<RC24_DELIVERY_DIRECTORY>\ODRE_PQC_PRODUCTION_0.3.0_CUSTOMER_DELIVERY.zip'
$expectedDelivery = '3A14BE4D12241CB2C675626958E7F6B6E4A86F2A77D53D92D14526B3277B5A0B'
if ((Get-FileHash -LiteralPath $delivery -Algorithm SHA256).Hash -cne $expectedDelivery) {
    throw 'RC24_DELIVERY_HASH_MISMATCH'
}
# Unpack this authenticated outer delivery only; do not extract the inner product ZIP.
if (Test-Path -LiteralPath '.\rc24-delivery') { throw 'DESTINATION_EXISTS' }
Expand-Archive -LiteralPath $delivery -DestinationPath '.\rc24-delivery' 
$python = '<TRUSTED_PYTHON_3_12_ABSOLUTE_PATH>'
& $python -B .\prepare_customer_verifier_config.py `
  --policy .\verifier-policy.json `
  --policy-sha256 '4BADE8AF01F2BC1F899F2B226604C690C27D6A7AE0A19C62A879AFCF90622FF5' `
  --platform windows `
  --cms-tool '<APPROVED_POWERSHELL_EXE_ABSOLUTE_PATH>' `
  --cms-tool-sha256 '<INDEPENDENTLY_APPROVED_POWERSHELL_SHA256>' `
  --operator-sid '<APPROVED_OPERATOR_SID>' `
  --output .\local-trust.json
if ($LASTEXITCODE -ne 0) { throw 'VERIFIER_CONFIGURATION_FAILED' }
& $python -B .\trusted_preinstall.py `
  --bundle '<RC24_PRODUCT_DIRECTORY>\ODRE_PQC_PRODUCTION_0.3.0.zip' `
  --envelope '<RC24_PRODUCT_DIRECTORY>\bundle-envelope.json' `
  --cms '<RC24_PRODUCT_DIRECTORY>\envelope.p7s' `
  --trust .\local-trust.json `
  --trust-sha256 '<RETURNED_TRUST_SHA256>' `
  --expected-bundle-sha256 '2A49C6F2FE0BA0702E615B6A55434E52F7826340B636FAB9F6FA1062ED389DC3'
if ($LASTEXITCODE -ne 0) { throw 'PREINSTALL_FAILED' }

Tras PREINSTALL=PASS sigue la guía RC24 firmada y la actualización que conserva la identidad. --install-new solo admite un destino nuevo vacío con ACL del padre aprobadas. No reinicialices el estado Trial, device o Gateway.

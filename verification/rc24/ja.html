Windows Server 2022の状態

対応 · 検証済み · PASS
Windows Server 2022 AMD64は検証済み6 OSの一つです。Public Authenticodeの有無とは別です。

公式release検証モデル

Release pin → CMS signing authority → signed CRL → independent verifier → signed outer inventoryと認証済みProduct envelope → manifest/SHA。失敗時はインストールを停止します。

独立検証手順

  1. 独立して認証した公式チャネルからRelease 64のhashとpinを取得します。
  2. 製品コード実行前にCustomer Delivery filenameとSHA-256を検証します。
  3. 固定rootとsignerでdetached CMSとsigned CRLを検証し、Private RootをWindows Trusted Rootへ登録しません。
  4. signed OUTER_INVENTORY、Product envelope、Product SHA、Ed25519 manifest、runtime inventory、sealed Core identityを検証します。
  5. 全Gate PASS後のみインストールし、identity、License、Unit、Lease、Gateway stateを保持します。

Windows Public Authenticodeの区別

Public Authenticodeはrelease trust authorityではなく、Windows Server 2022対応や6/6検証と混同しません。Windows保護を弱めません。

Evidence境界と今後のpublication binding

Release 64 CMSはsigned outer file inventoryと内部Product envelopeを結束します。g270 SHA256SUMSは最終ZIP hashを記録しますが、Release 64にはouter ZIP container bytesを結束するSigned Publication Manifestはありません。実装済みとは主張しません。今後の新Releaseから同じsigning authorityでfilename、size、SHA-256、Release、Closureを結束します。Release 64 Evidenceは遡及変更しません。6/6は製品Evidenceであり第三者認証ではありません。

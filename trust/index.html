03

Release Evidence

Release Gates 1 through 4 were completed within the recorded scope on Windows Server 2022 and Ubuntu 24.04. The documented evidence covers security attacks, replay and tamper rejection, state and Core failures, resource pressure, restart and recovery, bounded concurrency, and one-hour protected soak testing.

Within the validation scope, Protected Handler Bypass, Handler Double Execution, Plaintext Fallback, and Classical Fallback were all recorded as 0.

Validation coverage

  • Replay and tamper rejection
  • Invalid and expired session handling
  • Core unavailability and state read/write failure
  • Session expiry, restart, and recovery
  • CPU, memory, FD, and handle pressure

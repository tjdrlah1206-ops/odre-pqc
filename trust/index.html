Verify the file

Calculate SHA-256 on the delivered wheel before installation and compare every character. Obtain a new copy through the official delivery channel if it differs. Do not accept a hash supplied only alongside an untrusted copy.

# Windows PowerShell
Get-FileHash .\odre_pqc-0.2.9-py3-none-any.whl -Algorithm SHA256

# Ubuntu
sha256sum ./odre_pqc-0.2.9-py3-none-any.whl

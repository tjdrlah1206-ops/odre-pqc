Product

Protect selected FastAPI routes without replacing your application.

ODRE PQC installs inside a supported FastAPI service and places a fail-closed boundary in front of routes you designate as protected.

What it does

A security boundary, not a replacement for your stack.

ODRE PQC protects selected application routes. It does not replace TLS, authentication, authorization, secure coding, patching, host security, monitoring, backups or change control.

01

Protected-route admission

A protected handler runs only after the request satisfies the product's authenticated session and admission checks.

02

Request and response protection

The verified scope covers protected request meaning and protected response status, selected headers, cookies and body inside the product boundary.

03

Operational state

Initialization, diagnostics, verification and authenticated status checks support deployment decisions before protected traffic is admitted.

Integration model

Install, verify, connect, then admit traffic.

The supported workflow keeps cryptographic implementation details out of application handlers.

01 · Initialize

odre-pqc init

Create the local product state required for the supported environment.

02 · Diagnose

Check the installation and exercise the configured post-quantum operations.

03 · Integrate

04 · Operate

status

Confirm authenticated runtime state after application startup.

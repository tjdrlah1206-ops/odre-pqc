ODRE PQC Production 0.3.0

Production Bundle 0.3.0은 봉인된 ODRE PQC Core v0.2.9와 고객 설치, Native 런타임, 검증, 라이선싱 및 배포 계층을 함께 패키징합니다.

봉인 Core

v0.2.9

Production Bundle 0.3.0이 유지하는 봉인 Core 검증 기준선입니다. Linux F-028-01 경로에 parent-directory identity locking과 parent-dirfd-relative promotion을 추가한 뒤 봉인 Wheel로 Windows Server 2022, Ubuntu 22.04, Ubuntu 24.04, Debian 12, Rocky Linux 9, AlmaLinux 9 AMD64 전체 검증 범위를 다시 수행했습니다.

  • 공개September 2026
  • 호환성 변경v0.2.9 공개 백서에 breaking change가 기록되어 있지 않습니다.
  • 증거현재 artifact 식별정보와 무결성
History

문서화된 개발 이력

  • v0.2.8 → v0.2.9F-028-01 상위 객체 교체 방어와 대상·전체 재검증.
  • v0.2.6네이티브 신뢰, TOCTOU, file descriptor·inode 식별 강화와 provider·dependency·configuration 경로 검증.
  • v0.2.4 → v0.2.5Ubuntu native ABI 누락을 발견해 shutdown export와 lifecycle 동작을 수정했습니다. 이후 대상 감사에서 추가 finding이 확인되어 release blocking을 유지했습니다.
  • v0.1.4읽기 전용 status 관측 기능을 추가하고 기존 보안 계약을 다시 확인했습니다.
  • v0.1.3엄격한 next-sequence 검증과 지원하지 않는 응답 계약의 핸들러 전 거부로 v0.1.2 세 finding을 해결했습니다.
  • v0.1.2기능 검증 후 clean-room 공격 테스트에서 sequence-gap 허용과 handler ordering 결함 두 건을 보존했습니다.
  • v0.1.1보호 경로 plaintext 우회를 차단하고 보안 실패 뒤 fail-closed handler 동작을 확립했습니다.

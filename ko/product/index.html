ODRE PQC제품

FastAPI를 위한 포스트양자 보호.

ODRE PQC는 서버 내부에서 보호 요청을 검증한 뒤 FastAPI Handler를 실행합니다.

빠른 시작보호 방식
FastAPI 통합플랫폼 설치기로 제품을 설치한 뒤 ODRE PQC를 import하고 install(app)을 적용합니다.
Fail-ClosedUnverifiable protected requests stop before business handler execution.
Automatic operationsSigned updates, atomic switch, health checks and recovery are operated as one product lifecycle.
01

ODRE PQC란

ODRE PQC는 범용 암호 라이브러리가 아닙니다. 런타임 식별, 포스트양자 핸드셰이크, 세션 상태, 엄격한 순서 처리, 재전송 방어, 요청 의미, 보호 응답과 수명주기 통제를 하나의 FastAPI 실행 경계로 구성합니다.

포스트양자 알고리즘 호출만으로 검증한 런타임이 실제 로드되었는지, 재전송이 업무 핸들러를 두 번 실행할 수 없는지 보장되지 않습니다. 경계는 이런 질문을 보호 코드 실행 전 확인 조건으로 바꿉니다.

02

FastAPI 통합 방식

기존 클라이언트 → HTTPS/TLS → FastAPI → Gateway → ODRE v3 → Core → Protected Handler. 클라이언트 API 계약은 유지하며 ODRE v3는 모바일 단말과 서버 사이가 아닌 Gateway와 Core 사이에서 동작합니다.

Existing clientHTTPS / FastAPIGateway / ODRE v3Private CoreProtected Handler

플랫폼 설치기로 제품을 설치합니다. FastAPI에서 ODRE PQC를 import하고 install(app)을 호출합니다. Core·Native·Gateway, license/lease, session/replay, Fail-Closed, update lifecycle은 ODRE 내부에서 관리합니다.

표준 FastAPI 애플리케이션 통합

from fastapi import FastAPI
from odre_pqc import install

app = FastAPI()
install(app)

이 코드는 고객 대상 표준 애플리케이션 통합입니다. 제품 설치는 별도의 플랫폼 단계이며 ODRE가 내부 Core·Native·Gateway·Commercial gate 통합을 관리합니다.

고객은 FastAPI 애플리케이션, 보호 route와 Handler, 애플리케이션 인증·권한, business logic과 DB, 실제 보호 요청 검증, Production 승인을 담당합니다. ODRE는 내부 보안 경계와 lifecycle을 관리합니다.
03

보호 경로와 공개 경로

보호 경로

필수 보안 계약을 만족한 뒤에만 실행됩니다. 잘못된 메시지, 무효 세션, 중복·누락 순서, 의미 불일치, 신뢰할 수 없는 런타임 상태는 핸들러 진입을 차단합니다.

공개 경로

애플리케이션 정책에 따라 공개 health 또는 정보 경로는 계속 제공할 수 있습니다. Fail-closed가 모든 공개 경로 중단을 뜻하지는 않습니다.

04

배포와 운영 모델

  • Install공식 artifact의 Release Manifest 서명과 SHA-256을 확인한 뒤 Windows에서는 .\install-odre-pqc.ps1, Linux에서는 sudo ./install-odre-pqc.sh로 제품을 설치합니다.
  • initodre-pqc init은 신규 설치에서만 1회 실행합니다. 업데이트·재설치에서는 기존 설정·키·state를 보존합니다.
  • doctor플랫폼, 권한, 해시, 심볼, 의존성, 상태 저장소 접근을 진단합니다.
  • verifyodre-pqc verify는 임시 키·임시 DB로 ML-KEM-768·ML-DSA-65 등을 검사하는 독립 Core 암호 자체시험입니다. 설치 단계에서 실행하며 고객 FastAPI/Gateway 통합 증거로 간주하거나 그 목적으로 다시 실행하지 않습니다.
  • FastAPI 통합제품 설치 후 ODRE PQC를 import하고 install(app)을 적용합니다. 보호 route와 Handler, 애플리케이션 인증·권한을 구성하며 ODRE 내부 Core·Native·Gateway와 lifecycle 연결은 제품이 관리합니다.
  • status해당 Trial 또는 유료 활성화 절차를 완료하고 제품 status를 확인합니다. 고객 애플리케이션에서 실제 보호 요청과 예상 Handler·DB 동작을 검증한 뒤 Production 승인을 완료하고 트래픽을 개방합니다.
